| Invariant Core: Foundations of Mathematics |
| All consistent mathematical systems rest on logic and set theory. Truth is preserved through rigorous deduction. |
| Axioms are the unbreakable base: Undefined terms (set, element, belongs to) + ZFC (Zermelo-Fraenkel with Choice) or equivalent minimal consistent set. |
| Logic is prior: Classical first-order logic with modus ponens, law of non-contradiction, and excluded middle (in standard domains). |
| Numbers emerge: Natural numbers (Peano axioms) → Integers → Rationals → Reals (completeness) → Complexes. |
| Structure over objects: Mathematics studies relations, mappings, symmetries, and invariants under transformation. |
| Proof is the verification mechanism: A statement is true only if it follows deductively from axioms or previously proven theorems. |
| Infinity is handled carefully: Countable vs uncountable, potential vs actual, handled via limits, cardinals, ordinals. |
