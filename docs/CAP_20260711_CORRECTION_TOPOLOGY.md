## Stop-Condition Interpretation

Compartments do not themselves cause termination. They preserve the local scope in which termination can be evaluated.

```text
verified difference remains + valid correction exists → continue locally
objective threshold reached → accept and close
correction worsens result → reject and close
higher invariant fails → abort and close
budget exhausted → preserve uncertainty and close
no new verified difference remains → terminate
```

A closed boundary records the current resolved state. An open boundary identifies where verified difference remains actionable.
