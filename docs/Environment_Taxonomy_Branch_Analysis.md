| | An environment is defined relative to a subject and boundary.|
| |                                                              |
| | Let:                                                         |
| | S = subject under consideration                              |
| | B = declared system boundary                                 |
| | T = observation time or interval                            |
| | O = observer and observation procedure                       |
| | V = variables considered relevant                           |
| | I = interventions or controls                                |
| | D = declared dynamics or transition relation                 |

| | Then an environmental description is a bounded relation:     |
| |                                                              |
| | E = Environment(S, B, T, O, V, I, D)                         |
| |                                                              |
| | Changing S, B, T, O, V, I, or D can produce a different      |
| | environment description without requiring a new universal    |
| | environment type.                                           |
