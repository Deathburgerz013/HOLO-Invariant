With this spine we can roll forward and backwards in time.  
This spine contains only Chemistry invariants — fundamental rules of matter, bonding, and transformation that everyone (and machines) should remember forever. Chemistry bridges physics and biology.

|===========================================|
| Invariant Core: Atomic Theory & Conservation |
| Matter is composed of atoms with discrete structure (protons, neutrons, electrons). Atoms of the same element have the same number of protons (atomic number). |
| Conservation laws are absolute: Mass, charge, energy, and atoms are conserved in chemical reactions (Dalton + Lavoisier). No creation or destruction of atoms in ordinary chemistry. |
| Periodic Table organizes elements by atomic number and electron configuration → predictable trends in reactivity, electronegativity, atomic radius, ionization energy. |
| Chemical bonding arises from electron interactions: Ionic (electron transfer), Covalent (sharing), Metallic (delocalized). Bond strength determines stability. |
| Reactions follow stoichiometry: Balanced equations reflect conserved atoms and charge. Rate and equilibrium governed by kinetics and thermodynamics (ΔG, Le Chatelier). |
