| | LAYERED_TERRAIN_CANDIDATE                                    |
| | Let L denote a latent terrain that may not be fully observable.|
| | This symbol does not assert that one complete latent state is|
| | available or even representable.                            |
| |                                                              |
| | For declared scale or resolution r, let:                     |
| | pi_r be an observation or coarse-graining projection         |
| | X_r = pi_r(L) be the terrain representation available at r   |
| | Sigma_r be the feature and observation schema at r           |
| | U_r be interventions distinguishable at r                    |
| | W_r be exogenous inputs distinguishable at r                 |
| | K_r be the bounded transition relation represented at r      |
| | H_r be the bounded observation relation represented at r     |
| |                                                              |
| | Candidate scale-bound model:                                 |
| | M_(C,r) = (X_r, U_r, W_r, K_r, Y_r, H_r)                    |
| |                                                              |
| | Unknown layers remain explicit as structure not resolved by  |
| | pi_r and Sigma_r.                                           |
| | }==============================================================|
| | CROSS_SCALE_RELATIONS                                        |
| | For two declared scales r and s, a mapping:                  |
| | phi_(r->s): X_r -> X_s                                      |
| | may describe an attempted translation or aggregation.        |
| |                                                              |
| | The mapping must declare what it:                            |
| | • preserves                                                 |
| | • merges                                                    |
| | • discards                                                  |
| | • leaves unknown                                            |
| | • cannot reconstruct                                        |
| |                                                              |
| | No cross-scale mapping is assumed valid merely because both  |
| | representations refer to the same named terrain.             |
| | }==============================================================|
| | CANDIDATE_CROSS_SCALE_INVARIANTS                             |
| | A property may be called invariant across r and s only when a|
| | verified phi_(r->s) preserves that exact relation.           |
| |                                                              |
| | Candidate relations to test include:                         |
| | • reachability                                              |
| | • ordering                                                  |
| | • connected components                                      |
| | • boundary correspondence                                   |
| | • conservation constraints                                  |
| | • hazard existence                                          |
| | • identity bindings                                         |
| | • evidence lineage                                          |
| |                                                              |
| | None is declared universally preserved in advance.           |
| | }==============================================================|
| | GRADIENT_REQUIREMENT                                         |
| | A gradient requires a declared variable, neighborhood or     |
| | direction relation, scale, and difference procedure.         |
| |                                                              |
| | Symbolically, a gradient-like observation may be:            |
| | Grad_(r,v)(x)                                                |
| | where r is scale and v is the measured feature.              |
| |                                                              |
| | Without r, v, and a neighborhood relation, gradient is       |
| | underspecified.                                              |
| |                                                              |
| | A zero observed gradient may mean stability, insufficient     |
| | resolution, projection loss, or missing evidence.            |
| | }==============================================================|
