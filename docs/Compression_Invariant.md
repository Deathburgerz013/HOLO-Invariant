| | Compression is not the removal of information.              |
| |                                                             |
| | Compression is the process of increasing stability by       |
| | changing only what verified evidence requires.              |
| |                                                             |
| | Stability may require addition.                             |
| | Stability may require subtraction.                          |
| | Stability may require no change at all.                     |
| }=============================================================|
| | LOOP                                                        |
| | Observe                                                     |
| | Compare                                                     |
| | Verify                                                      |
| | Determine smallest required change                          |
| | Apply correction                                            |
| | Store                                                       |
| | Repeat                                                      |
| }=============================================================|
| | INVARIANT                                                   |
| | Compression seeks the smallest verified change that         |
| | increases stability.                                        |
| |                                                             |
| | Add only what is required.                                  |
| | Remove only what is required.                               |
| | Preserve everything else.                                   |
| |                                                             |
| | If no verified improvement exists,                          |
| | preserve the present state.                                 |
| }=============================================================|
| | STABILITY                                                   |
| | Stability is not produced by growth alone.                  |
| | Stability is not produced by reduction alone.               |
| |                                                             |
| | Stability emerges when the observable environment and the   |
| | stored structure agree with the smallest verified change.   |
| }=============================================================|
| | APPEND RULE                                                 |
| | Historical observations remain available for future         |
| | comparison unless verified evidence requires otherwise.     |
| |                                                             |
| | New observations extend the corpus.                         |
| | New verification restructures relationships.                |
| |                                                             |
| | The corpus grows by append.                                 |
| | The structure converges by verification.                    |
| }=============================================================|
| | CORRECTION_MARKER                                           |
| | Future evidence may change the current optimum.             |
| |                                                             |
| | Compression is therefore evaluated against the observable   |
| | environment at the time of the check.                       |
| }=============================================================|
| | TERMINAL_STATEMENT                                          |

| |                                                             |
| | Stability is achieved by adding, subtracting, or            |
| | preserving only what verified evidence demonstrates is      |
| | factually needed next.                                      |
