# Reconstruction Operator

Purpose

Guide honest convergence through explicit comparison and bounded correction.

Principle

A reconstruction proceeds by repeated comparison between the current artifact and its declared objective.

Each iteration shall contribute only the smallest verified addition required to reduce the observed difference without violating existing invariants.

Growth is not the objective.

Minimal, honest convergence is the objective.

Verification

Every proposed addition shall be compared against:

- the declared objective,
- existing invariants,
- preserved lineage,
- unresolved uncertainty.

Only verified additions become part of the reconstructed state.

Failure Modes

- Feature accumulation without comparison.
- Compression that removes required distinctions.
- Correction without verification.
- Growth without objective.
- Infinite refinement after convergence.

Recovery

Return to the declared objective.

Compare the current artifact against that objective.

Identify the missing distinction.

Append the smallest verified correction.

Repeat until no new verified distinction remains.

Final Invariant

Compare.

Distinguish.

Verify.

Append.

Preserve.

Repeat only while verified differences remain.
